The Genus Console design system

A visual style guide for the GenusLab admin console — built from what already exists in app/genuslab/**, refined into one consistent language for dashboards, tables, and forms that handle subscribers, quizzes, transactions, and payouts.

SurfaceAdmin console
Scopeapp/genuslab/**
Grounded inAdminCard, CustomSelect, inputStyles.ts
StatusDocumentation only — no code changed
01

Design philosophy

The console manages people's money, quiz progress, and payouts. Every screen should read as accurate first, attractive second.

What this system is

  • Editorial-enterprise: a clean grid, strong type hierarchy, and generous but disciplined whitespace — closer to a banking back-office than a marketing dashboard.
  • Built on what exists: the Slate/Blue palette, AdminCard, and the inputStyles.ts form primitives already in the repo are the foundation — this refines them, not replaces them.
  • Density with clarity: tables and filter bars favour information density; empty states and metrics favour breathing room.

What it deliberately avoids

  • Dark mode, glassmorphism, glow, and heavy gradients — reserved for the learner-facing quiz app, never the admin console.
  • Decorative shadows and 16–40px "bubble" radii — the console currently borrows rounded-2xl cards and a 40px-radius modal from the consumer side; both read as consumer, not administrative.
  • Colour used as the only signal — every status also carries a label and a shape (dot, icon, or badge), never colour alone.

Financial & data presentation

This console moves real money. Every rule here exists so a number can't be misread at a glance.

Data typeRule
Currency₦12,450,000.00 — Naira sign, thousands separators, always 2 decimals, IBM Plex Mono, right-aligned in tables
Negative valuesLeading minus and #B91C1C colour together — never colour alone (a red-green-blind admin still needs the minus sign)
PercentagesOne decimal, signed (+8.4% / -2.1%), paired with an ↑/↓ glyph — never colour-only trend
Large numbers (KPI cards)Abbreviate to 1 decimal (₦24.8M) with the exact figure available on hover/tooltip
Dates12 Mar 2026 in tables; relative form ("3 days ago") only in secondary/caption text, with the exact date on hover
IDs / reference numbersMono, muted (#94A3B8), never bolded — a reference number should never compete with the row's real content

18

Accessibility

  • Contrast: every text/background pairing in this guide meets WCAG AA (4.5:1 body text, 3:1 for 18px+/700 headings) — verified against the neutral and semantic tokens above.
  • Colour is never the only signal: status always pairs with a label; negative values always pair with a minus sign; trends always pair with an arrow.
  • Focus order follows visual order — sidebar, header, filters, table, pagination — with a visible 2px ring at every stop.
  • Labels: every input has a real <label> tied via htmlFor, not a placeholder standing in for one.
  • Custom dropdown a11y: full combobox/listbox ARIA pattern (see §11) since it replaces a native, already-accessible <select>.
  • Touch targets ≥40px on touch viewports, ≥24px with 8px spacing on desktop pointer targets.

Codebase alignment

What to keep as-is, refine, standardise, remove, or introduce — scoped to app/genuslab/** and its layout/UI components only.

KEEPAdminCard, AdminSidebar, AdminHeader, CustomSelect + inputStyles.ts, the LinePie donut pattern, the users/transactions table+filter+pagination shape, zustand for sidebar state, react-query for data fetching.
REFINEAdminCard radius 16px→12px; give AdminHeader a fixed 64px height; consolidate the two toast libraries to react-hot-toast only for admin surfaces; fix the quoted-string bug on --color-dark/--color-accent.
STANDARDISEExtract the repeated table pattern into a shared <DataTable>; extract STATUS_STYLES into a shared <Badge status=>; extract the Previous/Next footer into a shared <Pagination>; give CustomSelect a typed prop interface (currently any) and use it in place of every native <select> in users and transactions.
REMOVEEmpty Secondary.tsx/Danger.tsx/Success.tsx button stubs (replace with the variants in §10); duplicate fadeIn keyframe; the broken linear() gradient tokens; the touquise typo token; react-icons imports in any admin file going forward.
INTRODUCEA MetricCard variant of AdminCard (icon chip + big number + delta, §08); an ARIA-complete, searchable version of CustomSelect (§11); IBM Plex Mono as the numeric typeface (§03); the content max-width token (§06).
